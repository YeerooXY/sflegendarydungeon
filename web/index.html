    About this model

    Some room probabilities, damage distributions and opening sequences remain provisional. Shops are compulsory; later runs have none in stage one. Base escape is 40%. Simulated time advances on actions, recovery and scheduled sleep; time spent thinking does not count. Daily availability is set when starting an event. Game artwork is loaded locally from your installation and is not included in the open-source project. Creature illustrations do not identify a separate damage model.
